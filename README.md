# Lab128Next - bugs and suggestions

Public place for bug reports and suggestions about Lab128Next (the source code is in a private repository).

- **Bug**: in Lab128Next use **Help › Report a Bug** (or the bug icon at the right of the menu bar). It opens a new issue
  here filled in and creates a `.zip` with the logs and the versions (text only), with the names of databases, hosts and
  users hidden: drag the `.zip` into the issue before submitting.
- **Suggestion**: **Help › Send a Suggestion** (or the light bulb icon). Suggestions get the `enhancement` label;
  add a 👍 reaction to the ones you want too.

Issues are public: do not paste passwords, connection strings or names of customers.
